Linear Regression Theory

Hypothesis, cost function, gradient descent & closed-form solution

📖 Hypothesis Formulation

Linear regression assumes the target variable y is a linear combination of input features plus Gaussian noise.

Simple Linear Regression
ŷ = β₀ + β₁·x
where β₀ = intercept, β₁ = slope
Multiple Linear Regression (vectorized)
ŷ = β₀ + β₁x₁ + β₂x₂ + … + βₙxₙ = βᵀx

📖 Cost Function — What Are We Minimizing?

The cost function J(β) measures how "wrong" our predictions are on average. We use Mean Squared Error (MSE). Squaring penalises large errors more harshly and produces a smooth, differentiable surface convenient for optimisation.

J(β) = (1/2m) · Σᵢ ( ŷᵢ − yᵢ )²
where m = number of training samples

The cost surface is a convex paraboloid — exactly one global minimum.

📖 Gradient Descent — Iterative Optimisation

Gradient Descent iteratively adjusts parameters by moving in the direction of steepest descent on the cost surface. The learning rate α controls step size. Too large → overshoots; too small → slow convergence.

Update Rule
β₀ := β₀ − α · (1/m) · Σ(ŷᵢ − yᵢ)
β₁ := β₁ − α · (1/m) · Σ(ŷᵢ − yᵢ)·xᵢ
Vectorized (Multiple LR)
β := β − (α/m) · Xᵀ(Xβ − y)

📖 Normal Equation — Closed-Form Solution

For linear regression, we can solve for the optimal parameters analytically by setting the gradient to zero. This avoids iterative optimisation but requires matrix inversion (O(n³) — expensive for large feature sets).

Optimal Parameters (Matrix Form)
β = (XᵀX)⁻¹ · Xᵀ · y

Exact solution in one step — O(n³) cost. Preferred for small feature sets.

Simple LR Closed Form
β₁ = Σ(xᵢ−x̄)(yᵢ−ȳ) / Σ(xᵢ−x̄)²
β₀ = ȳ − β₁·x̄

🐍 How scikit-learn Implements This

sklearn.linear_model.LinearRegression uses LAPACK's DGELS routine (optimised QR decomposition) — a numerically stable version of the Normal Equation.
